# Music-Player

    ~  This Web Music Player is a responsive audio playback application built using HTML, CSS, and JavaScript. 
    ~  It allows users to upload and play songs, 
    ~  view metadata like artist and album, 
    ~  manage a dynamic playlist, 
    ~  control volume and playback, and visualize the music through animated graphics. 
    ~  The player includes features such as theme switching, a progress bar with a timer, and real-time playlist search.
    ~  It provides a modern, interactive interface and a seamless user experience.
